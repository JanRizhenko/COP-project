# Інструкція користувача та обмеження використання

**Проєкт:** Hanoi Tower Game (вежі Ганоя)  
**Версія:** 1.0.0  
**Автор:** Jan Rizhenko  

## 1. Призначення

Це навчальний веб-застосунок для гри «Вежі Ганоя»: переміщення дисків між стрижнями з дотриманням правил головоломки. Проєкт призначений для демонстрації структури React-застосунку, маршрутизації, контексту стану та супутньої документації (JSDoc, Storybook).

## 2. Системні вимоги

- Сучасний браузер з увімкненим JavaScript.
- Node.js LTS та npm для збірки та локального запуску (див. `README.md`).

## 3. Як користуватися

1. Встановіть залежності: `npm install`.
2. Запустіть режим розробки: `npm start`.
3. На стартовій сторінці введіть ім’я гравця та параметри гри, почніть нову гру.
4. Дотримуйтесь підказок у інтерфейсі для переміщення дисків між стрижнями A, B, C.

Докладні команди збірки, тестів і документації — у `README.md`.
