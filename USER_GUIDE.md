# User Guide And Usage Limitations

**Project:** Hanoi Tower Game  
**Version:** 1.0.0  
**Author:** Jan Rizhenko  

## 1. Purpose

This is a web application for the Tower of Hanoi puzzle: moving disks between rods while following the puzzle rules. The project shows React app structure, routing, state/context management, and supporting docs (JSDoc, Storybook).

## 2. System Requirements

- A modern browser with JavaScript enabled.
- Node.js LTS and npm for local build/run (see `README.md`).

## 3. How To Use

1. Install dependencies: `npm install`.
2. Start development mode: `npm start`.
3. On the start page, enter player name and game settings, then begin a new game.
4. Follow the UI prompts to move disks between rods A, B, and C.

Detailed build, test, and documentation commands are listed in `README.md`.
